Local Graph-View-Agent

See your LangGraph run as it happens.

GraphVIAgent is a local inspector for LangGraph. Point it at a folder of *_pipeline.py files, press Run, and watch topology, steps, state, and logs update live. Pipelines stay uninstrumented. Nothing is sent to LangSmith. Only the runs you start are stored.

Features

Live topology

The graph is a map of your pipeline, not an unrolled column. Cards pulse while a node runs. Taken, skipped, loop, and parallel edges stay on one picture, including ×N fan-out.

Steps, Gantt, Agents

Switch the same run between a topology map, a Gantt of wall time, and an Agents view when nodes return messages. Click a node to select it. Double-click to open Node view.

Logs you already write

print() and stderr are captured as PRINT / STDERR. Python logging keeps its level. DEBUG, INFO, WARN, ERROR, and CRIT each have their own color. Logger names show when they differ from the node.

Replay a node, or from a node

Replay step runs only the selected node. Replay from continues the graph from that node. Both invoke the real function — side effects will fire. Outdated runs (graph hash changed) ask before replay.

Pipelines board and Compare

Pipelines is an Airflow-style grid of duration and task × run. Compare diffs input, path, per-node output, and timing between two runs.

Cancel, three at a time

Up to three runs can execute together. Cancel is cooperative: an in-flight sleep finishes, then the run stops. History keeps failed runs.

Local history

Each run is JSON under .graphviagent/runs/<pipeline>/. Export, import, or drop a file on the run list. Search input fields. Filter success or failed.

State you can trust

Final state, a Memory table of who wrote and read each key, and a per-node state diff in Node view. Optional decisions, reason, and choice label branches on the graph.

Start

1. Install

Python 3.10 or newer. Use a virtualenv.

python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install graphviagent

The package does not copy example files into your project. You add your own pipeline.

2. Add a pipeline

The file name must end with _pipeline.py. Save this as echo_pipeline.py in an empty folder:

from typing import TypedDict
from langgraph.graph import END, START, StateGraph

EXAMPLES = [
    {"label": "hello", "input": {"text": "hello"}},
    {"label": "GraphVIAgent", "input": {"text": "GraphVIAgent"}},
]

class EchoState(TypedDict):
    text: str
    echoed: str
    length: int

def echo(state: EchoState) -> dict:
    text = state["text"]
    return {
        "echoed": text[::-1],
        "length": len(text),
        "reason": f"reversed {len(text)} chars",
    }

def build_graph():
    graph = StateGraph(EchoState)
    graph.add_node("echo", echo)
    graph.add_edge(START, "echo")
    graph.add_edge("echo", END)
    return graph.compile()

EXAMPLES is optional. The first item prefills the input box. Use {"label": "…", "input": {…}} or a bare dict.

3. Open the UI

graphviagent serve . --open

Or open http://127.0.0.1:8765. Leave the terminal running. New or edited *_pipeline.py files refresh the sidebar without a restart.

graphviagent serve . --port 9000
graphviagent serve . --host 127.0.0.1

4. Run

  1. Select the pipeline in the sidebar.
  2. Edit the JSON input if you need to.
  3. Click Run. The topology appears immediately and pulses while nodes execute.
  4. Single-click a node to select it. Double-click to open Node view.

Manual

Pipeline contract

A file is viewable if it is named *_pipeline.py and exposes one of:

  • build_graph() / get_graph() / create_graph()
  • compiled GRAPH or app
  • __graph__ = "factory_name"

Do not import GraphVIAgent in the pipeline. The viewer loads the file and records runs you start from the UI or CLI.

Trace

  • Graph — static map of nodes and edges. Taken paths, skipped branches, loops, and parallel Send fan-out.
  • Gantt — wall-clock bars per node. Hover for timing, memory, and tokens when present.
  • Agents — speaker chain when a node returns messages.
  • Steps — visit order with duration and spark metrics.
  • Final state, Log, Memory, and Text tree fold under Steps.

History search matches input fields. Filter all / success / failed. Export downloads the open run as JSON. Import or drop a file on the run list. Delete run removes the open run.

Node view

Shows node input, output, a state diff (state_in vs state_out), and tools when the update has tool calls. Call node is the same as Replay step: it invokes the real node.

Replay

Replay step re-runs only the selected node with its recorded input (or an edit you make). Replay from continues the graph from that node. Both hit your real functions. If the pipeline file or graph hash changed, the run is marked outdated and replay asks before continuing.

Pipelines

Airflow-style cards: duration bars, then task × run (✓ / ✕ / ○). Click the name to open Trace. Click a bar, cell, or play control to open that run. Clear deletes every run for that pipeline.

Compare

Open Compare. Filter by pipeline (default all). Pick Run A and Run B. Diff input, path, per-node output, and timing. Hover a cell to copy.

Privacy and storage

Everything stays on your machine. Runs are written under the folder you served or ran from:

my_graphs/.graphviagent/runs/echo_pipeline/<id>.json

Add .graphviagent/ to .gitignore.

Limits

  • Alpha: APIs, UI, and on-disk run format may change.
  • Local only. Nothing is uploaded.
  • logging still respects the logger’s level. Root defaults to WARNING, so logger.info appears only if that logger is enabled for INFO.
  • Cancel waits for the current blocking call (for example sleep) to return.

CLI

CommandWhat it does
graphviagent .
graphviagent list .		 List *_pipeline.py files under a folder.
graphviagent run echo_pipeline.py --input '{"text":"hi"}' Record a run without the browser. Stored under .graphviagent/ in the current directory. Exit status is 1 if the graph raised.
graphviagent serve .
graphviagent serve . --open		 Open the local UI (default 127.0.0.1:8765). --open launches a browser. --host and --port override the bind address.

With a clone of the repo you can also run graphviagent serve examples to browse the bundled pipelines (branch, loop, parallel Send, tools, agents, errors).
