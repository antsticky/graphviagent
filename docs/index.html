See your LangGraph run as it happens.

GraphVIAgent is an inspector for LangGraph. Point it at a folder of *_pipeline.py files, press Run, and watch topology, steps, state, and logs update live. Pipelines stay uninstrumented. Only the runs you start are stored.

Features

Watch a run live, replay a node, then see every visit on the board, in Compare, and in Statistics.

Live topology

The graph is a map of your pipeline, not an unrolled column. Cards pulse while a node runs. Taken, skipped, loop, and parallel edges stay on one picture, including ×N fan-out.

Steps, Gantt, Agents

Switch the same run between a topology map, a Gantt of wall time, and an Agents view when nodes return messages. Click a node to select it. Double-click to open Node view.

Logs you already write

print() and stderr are captured as PRINT / STDERR. Python logging keeps its level. DEBUG, INFO, WARN, ERROR, and CRIT each have their own color. Logger names show when they differ from the node.

Replay a node, or from a node

Replay step runs only the selected node. Replay from continues from that checkpoint so routing can take the other branch. Both invoke the real function — side effects will fire. Outdated runs (graph hash changed) ask before replay.

Runs board and Compare

Runs is an Airflow-style grid of duration and task × run. Compare diffs input, path, per-node output, and timing between two runs, including each visit when a node ran more than once.

Statistics: Routing, Runtime, and Cost

Same topology as Trace. Routing shows run count, average node visits, and success vs failed vs canceled. Runtime writes average duration, a pipeline grand total, and average vs longest run. Cost writes average in/out tokens, a pipeline grand total, and average per run. Hover a color strip for a dotted legend (one label per color). Colored jumps keep you on that pipeline.

Cancel, three at a time

Up to three runs can execute together. Cancel stops an in-flight run or a paused one. time.sleep is interrupted within ~50ms. Other blocking calls still finish first. History keeps failed and canceled runs as separate statuses.

Local history

Each run is JSON under .graphviagent/runs/<pipeline>/. Export, import, or drop a file on the run list. Search input fields. Filter success, paused, canceled, or failed.

State you can trust

Final state, a Memory table of who wrote and read each key, and a per-node state diff in Node view. Optional decisions, reason, and choice label branches on the graph.

Start

Install the package, drop a pipeline in a folder, press Run.

1

Install

Python 3.11 or newer. Use a virtualenv.

python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install graphviagent

The package does not copy example files into your project. You add your own pipeline.

2

Add a pipeline

The file name must end with _pipeline.py. Save this as echo_pipeline.py in an empty folder:

from typing import TypedDict
from langgraph.graph import END, START, StateGraph

EXAMPLES = [
    {"label": "hello", "input": {"text": "hello"}},
    {"label": "GraphVIAgent", "input": {"text": "GraphVIAgent"}},
]

class EchoState(TypedDict):
    text: str
    echoed: str
    length: int

def echo(state: EchoState) -> dict:
    text = state["text"]
    return {
        "echoed": text[::-1],
        "length": len(text),
        "reason": f"reversed {len(text)} chars",
    }

def build_graph():
    graph = StateGraph(EchoState)
    graph.add_node("echo", echo)
    graph.add_edge(START, "echo")
    graph.add_edge("echo", END)
    return graph.compile()

EXAMPLES is optional. The first item prefills the input box. Use {"label": "…", "input": {…}} or a bare dict.

3

Open the UI

graphviagent serve . --open

Or open http://127.0.0.1:8765. Leave the terminal running. The UI only accepts requests from its own origin. Bind stays on localhost unless you pass --expose:

graphviagent serve . --port 9000
graphviagent serve . --host 127.0.0.1
graphviagent serve . --host 0.0.0.0 --expose

--expose prints a warning. Anyone who can open that URL can run your pipelines and read stored runs. New or edited *_pipeline.py files (and toml-listed pipelines, including files outside the serve root) refresh the sidebar without a restart.

4

Run

  1. Select the pipeline in the sidebar.
  2. Edit the JSON input if you need to.
  3. Click Run. The topology appears immediately and pulses while nodes execute.
  4. Single-click a node to select it. Double-click to open Node view.

Manual

Four rooms, one pipeline. Jump Trace, Runs, Statistics, and Compare without losing the graph.

Live inspector

Trace

The graph is a map, not an unrolled column. Cards pulse while a node runs. Taken, skipped, loops, and parallel Send stay on one picture.

  • Graph / Gantt / Agents — topology, wall-clock bars, or a speaker chain when a node returns messages.
  • Steps — visit order with duration and spark metrics. Final state, Log, Memory, and Text tree fold under it.
  • Gutter dots are breakpoints. Continue / Step pause again. HITL graphs (interrupt(...)) pause with a resume-value box; Continue sends it.
  • Replay step re-runs one node. Replay from continues from that checkpoint so routing can take the other branch. Side effects fire. Outdated graph hashes ask first.
  • Export, import (or drop JSON), then Runs / Statistics jump to this pipeline. Delete run is red, same size as the others.

Statistics

Same topology as Trace. Pick a pipeline — there is no all view. Colored jump buttons (not the header menu) keep you on that graph.

  • Routing — run count, average node visits, success / failed / canceled split. Click a node for grouped branch reasons.
  • Runtime — wall-clock grand total, average per run, violet average vs orange longest run. Click a node for min / avg / max.
  • Cost — average in/out tokens per node, a pipeline grand total, and average per run. Tokens, not dollars.
  • Hover a color strip for a legend of color dots and labels, one per line.

Pipeline contract

A file is viewable if it is named *_pipeline.py (or listed in graphviagent.toml) and exposes, in this order:

  • build_graph() / get_graph() / create_graph() / __graph__
  • compiled or StateGraph GRAPH
  • compiled app (stream and invoke only)

Do not import GraphVIAgent in the pipeline. The viewer loads the file and records runs you start from the UI or CLI.

graphviagent.toml

Optional project file. root and pythonpath are resolved relative to the toml, so from app.graph import build_graph works no matter where you launch serve.

root = "."
pythonpath = ["."]
env_file = ".env"
context = {}

[pipeline.decision]
file = "decision_pipeline.py"

With [pipeline.*] tables, those files are the graphs (file may be any .py, including a path outside the serve root). Those files are watched too. Without them, GraphVIAgent globs *_pipeline.py.

Privacy and storage

Everything stays on your machine. Runs are written under the folder you served or ran from:

my_graphs/.graphviagent/runs/echo_pipeline/<id>.json

Each run file has schema_version (currently 1) and gva_version. Older files still load. Import of a newer schema is refused. Add .graphviagent/ to .gitignore.

Limits

  • Alpha: APIs, UI, and on-disk run format may change.
  • Local only. Nothing is uploaded.
  • logging still respects the logger’s level. Root defaults to WARNING, so logger.info appears only if that logger is enabled for INFO.
  • Cancel interrupts time.sleep quickly. Other blocking calls (network, LLM) still finish before the run stops.

CLI

List, run, and serve from the folder that holds your pipelines.

graphviagent .
graphviagent list .

List *_pipeline.py files under a folder.

graphviagent run echo_pipeline.py --input '{"text":"hi"}'

Record a run without the browser. Stored under .graphviagent/ in the current directory. Exit status is 1 if the graph raised.

graphviagent serve .
graphviagent serve . --open

Open the UI (default 127.0.0.1:8765). --open launches a browser. --host and --port override the bind address. Binding beyond localhost requires --expose (and prints a warning): the server runs your pipeline Python, and only same-origin pages may call it.

With a clone of the repo you can also run graphviagent serve examples to browse the bundled pipelines (branch, loop, parallel Send, tools, agents, waits, errors).
